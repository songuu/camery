## 调研说法的核对结论

下表是事实定位及待审工程解释；“已找到原文”不等于法务/产品已经签核。

| 待核说法 | 原文支持到哪里 | 工程结论 / 剩余项 |
|---|---|---|
| 2026-09-01实施、AI微短剧逐集提示 | S1第34、54条支持；适用范围另见第2条 | 日期与逐集要求有正式来源；客户的制作/播出角色、项目是否属于适用对象仍待确认 |
| 按投资额自动分类备案 | S1第5条同时涉及投资与题材，数额标准另行制定；第17条区分许可、批准文件、播出单位播前审核及节目编号 | 不能仅从预算推导类别，不能把三类都视为同一种备案/许可证流程 |
| 30万/100万元是当前统一硬阈值 | S9–S11已取得部门公开说明/转载，真人与AI口径不同，见下节；总局分类提示正式原件、完整文号及项目适用细则仍未取得 | 不能继续视为统一硬阈值；不把部门说明直接升级为已签核的自动分类规则，也不从缺原件推断“未发布” |
| “凡播必审”可做单一自动布尔项 | S1第17、33条存在不同审核责任和凭证 | 需记录类别、责任主体和凭证；不虚构已获许可或播出单位审核结果 |
| AIGC标识是2026才开始 | S2第14条与S3登记均指向2025-09-01 | 与S1的2026逐集要求分开建档，不能合并为一个生效日期 |
| 显式标识完全由客户任意开关 | S2第4条要求结合相应服务情形；第9条另有协议/日志条件，第10条约束恶意移除 | 现有方案中的配置选项不是无条件豁免；产品适用性和例外流程待签核，本轮不实现去标识能力 |
| 私有部署天然不适用标识要求 | S2第2条按服务情形界定主体，不能只看部署位置 | 需核对客户是否对公众提供服务、谁生成及传播；私有部署不自动填“免除” |

## 分类金额：已取得的部门公开信息与剩余缺口

2026-11-16实际打开S9–S11全文。S9将真人与AI分别描述：

| 形态 | 一类的金额说明 | 二类的一般题材金额说明 | 三类的一般题材金额说明 |
|---|---|---|---|
| 真人微短剧 | 300万元及以上 | 100万元（含）至300万元 | 不足100万元 |
| AI微短剧 | 80万元及以上 | 30万元（含）至80万元 | 不足30万元 |

该表只整理S9的公开表述。特殊题材另有分类条件，不能仅看投资额；二类上端点需结合一类条件和正式文本核对，不能将本表当作已经确认的闭区间程序。S1第17条的许可证、批准文件、播出单位播前审核/节目编号仍分开记录。

S10描述的是2026年1月调整，S11描述的是7月AI专项提示，S9描述的是9月新办法框架；不能把不同时间的“重点/普通/其他”与“一/二/三类”标签直接视为同一版规则。S10同页的300万元端点措辞存在差异，且S9不是分类提示正式文件。当前已不再是“没有任何金额公开依据”，但仍缺发行机关提示的正式全文/文号及目标项目、所在地主管部门的适用确认。没有用媒体独家报道替代该缺口。

工程处理：保持人工核对，不修改IR、预算或发布闸门，不按上述数字自动判定分类。法务/产品须确认有效版本、制作形态、题材、投资口径、时间及申报地后，才能批准具体规则和测试边界；本轮没有预填客户地点、题材或分类结论。

## 元数据字段：规范性附录E

以下从S4印刷页13（PDF第17页）的**规范性附录E**核对；第6.1节要求单份隐式标识。各字段值为字符串，标签 `Label` 的 `1/2/3` 分别表示确定、可能、疑似生成合成。扩展字段名/关键词含 `AIGC`，值按附录E的字符串格式承载。[原文](https://www.xiongan.gov.cn/20250617/99e8309670814bdba91b3bcbfaca4e6c/2025061799e8309670814bdba91b3bcbfaca4e6c_38598ff9004470443c9195f1655adb29a0.pdf)

| 字段拼写 | 含义 |
|---|---|
| `Label` | 生成合成属性 |
| `ContentProducer` | 生成服务方名称/编码 |
| `ProduceID` | 制作内容唯一编号 |
| `ReservedCode1` | 生成方安全防护预留 |
| `ContentPropagator` | 传播服务方名称/编码 |
| `PropagateID` | 传播内容唯一编号 |
| `ReservedCode2` | 传播方安全防护预留 |

工程解释：不采用资料性附录F示意图中的不同拼写覆盖附录E。首次写入时两方/编号的关联、字符约束与安全防护做法须按原文实现；不能用测试编号、文件哈希或“自称服务商”代替真实主体及内容编号。这里未生成任何客户标识值。
