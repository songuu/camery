# 声音、肖像、改编与素材授权台账模板

版本：`template-2026-11-11.1`。状态：待真实项目登记；**当前真实授权记录为零**。依据与签核边界见[原文核对包](phase0-source-review.md)。这是手工登记模板，不是已部署的数据库/权限系统、合同文本或授权证明。

每个授权范围建立一条记录，关联具体Source/Asset/声音/肖像对象及版本。合同号、付款记录、文件存在或SHA-256只提供追溯线索，不自动将状态改为“已核验”。原件、身份证明、签名、声纹和真人肖像留在有访问权限的材料库，台账只保存受控引用；不要提交到公开仓库、诊断日志或外部模型。

## 一条记录的填写卡

| 字段 | 填写要求 |
|---|---|
| 台账ID / 修订号 | 项目内稳定编号；修改范围时递增修订，保留旧记录 |
| 租户 / 项目 / 负责人 | 内部身份与维护责任，不用公开艺名代替主体核验 |
| 对象与版本 | source/asset/voice/portrait等ID、版本、使用位置；替换文件另记版本 |
| 材料类别 | 原著改编、真人肖像、声音/仿声、音乐作品、录音制品、表演、字体、图片/视频、音效等；可能同时涉及多项权利 |
| 权利人 / 授权链 | 谁有权许可、代理/转授权依据及授权对象；经手联系人不自动等于权利人 |
| 合同 / 许可版本 | 合同号、签署日期、许可版本、受控存档引用；缺证记缺证 |
| 原件追溯 | 可选文件摘要、材料类型及保存位置/访问组；摘要不能证明合同有效 |
| 明确允许的行为 | 改编、摄制、复制、传播等分别登记；训练/克隆/仿声/商业成片/投放是否允许须单列，未写明不代填“全部” |
| 适用对象与范围 | 项目/作品、素材、生成模型或服务、交付版本、平台、地域、语言、期限、次数/数量等合同限制 |
| 排他 / 转授权 / 再许可 | 依据原件填写；不从“可商用”推导全部权限 |
| 署名 / 费用 / 其他条件 | 署名位置、付费状态及限制条款的受控引用，不复制不必要的财务隐私 |
| 有效期 / 撤回 / 终止 | 起止日期、撤回或终止约定、届时受影响对象及处理责任；不承诺既有发布能自动撤回 |
| 核验状态 | 未收集、材料已收、待核验、限定范围核验通过、拒绝、到期、撤回/终止；状态不替代范围内容 |
| 核验人与证据 | 核验人职责、时间、结论、原文条款、适用限制；空白不得填成通过 |
| 后续行动 | 待补材料、责任人、期限、影响镜头/取用/交付/发布清单 |

## 分项核对

| 类别 | 需要明确回答的问题 |
|---|---|
| 小说/剧本及改编 | 原作品与改编作品分别是谁的权利？许可涵盖改编、摄制、传播及目标地域/期限吗？主张原创/公有领域的依据是什么？ |
| 真人肖像 | 是否涉及可识别自然人、是否允许当前制作和公开用途？适用例外由审阅人记录，不能从素材公开可下载推导许可 |
| 声音/仿声 | 录音内容、录音制品、表演和自然人声音是否分别有适用依据？是否明确覆盖克隆/仿声、模型输入及目标用途？ |
| 音乐/音效 | 作品、表演与录音制品可能涉及不同权利；购买文件或服务套餐不自动替代逐项范围核验 |
| 字体/图片/视频 | 记录实际许可版本和安装/生成/成片/广告等用途限制；不要将免费获得、开源代码或工具许可等同于素材许可 |
| 生成服务输出 | 保存实际服务条款/模型许可版本及商用、输入/输出范围；不能仅凭输出文件生成成功推导无第三方权利问题 |

上述问题是项目核验设计，不把每种材料一律认定为受同一种权利或合同形式约束。法定例外、权属争议和保护期限判断转交实际法务/权利核验角色；原文位置见[来源S5/S6](phase0-source-review.md)。

## 交付前核对记录

1. 列出本次版本实际消费的来源、人物声音/肖像、素材及派生链，匹配其对象版本。
2. 逐条检查使用行为和范围；不能仅看一个布尔“授权”字段。缺证、范围不符、已过期/撤回须明确记录，不能静默补许可。
3. 将例外依据、未解决事项和签核人关联到交付记录。拟定的产品门禁须另外实施及验收；模板本身不产生交付/发布授权。
4. 对外交接只提供必要摘要和受控材料引用，遵守材料访问边界；未授权的第三方不应随包取得原始个人资料。

现有IR中的rights_status、usage_basis、consent_ref仍只是当前实现的声明字段，不会因填写本模板自动变成真实权属、合同鉴真或完整合规结论。
