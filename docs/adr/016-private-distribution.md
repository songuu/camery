# ADR-016：容器、离线包与签名授权

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

Studio 首发私有化，需要单服务器部署、离线运行和可管理升级；公司侧不交付源码。按照 [实施计划 v2.1 第 2、7 章](../plan/implementation_plan_v2.md) 与 [产品方案 2.3](../product/solution_v2.md)，采用容器镜像 + Compose、离线包、Ed25519 签名授权、内容包独立签名发布；迁移前自动备份。

app（API / worker / 前端）与 media-py 按既定部署结构交付，先支持 x86_64。授权记录客户、版本档、席位、有效期和功能开关；过期宽限后转只读，不锁住客户数据。项目锁定内容包版本，升级由用户选择；企业版可选源码托管。

## 代价与边界

需要维护镜像、安装检查、离线材料、升级迁移、恢复和授权安全。签名与加密不能承诺客户环境中的内容绝对无法提取；合同约束仍是保护的一部分。只有数据库容器或 Compose 配置可展开，不等于完整产品可部署。

## 实施与验证条件

- T0.1：从首日起使用私有化档案；各服务按实际实现加入，不创建虚假可运行状态。
- T4.5、T4.8：干净 Linux 服务器按文档 30 分钟内部署、离线安装、备份恢复和升级失败回滚通过。
- T4.5、T4.7：授权篡改拒绝、席位生效、过期只读且客户数据完整；凭据、TLS、RBAC、诊断脱敏与限流通过安全验证。
- 内容包独立验签，项目版本不会被后台热更新静默改变；未授权或失败更新保留原采用版本。
