# ADR-010：FFmpeg 与工坊模板渲染

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

Studio 需要静帧运镜、动态分镜、拼接、抽帧和声音时长测量，个人知识工坊还需要模板化成品。按照 [实施计划 v2.1 第 2、5 章](../plan/implementation_plan_v2.md)，采用 FFmpeg；工坊阶段增加无头 Chromium 模板渲染，不把这一依赖提前变成 Studio 必需组件。

媒体处理由 Python 媒体服务承载相关能力。实测声音和素材时长驱动下游时间安排；媒体产物需探测参数并校验，不能只看进程退出码。

## 代价与边界

需要管理编解码、封装、字体、模板和运行环境的差异。文件存在及 SHA-256 相符不证明画面内容正确；元数据检查不等于全部合规。公司侧不自研调色、混音母带或通用剪辑器。

## 实施与验证条件

- T0.7、T0.13：连接器产物可下载、探测并进入测试；交付可行性使用真实样例与目标后期软件验证。
- T3.1、T3.2、T3.5、T3.9：声音先行、动态分镜、漫剧档和接戏抽帧完成媒体参数与音画同步验收。
- T4.3：标识字段及适用格式先经 T0.11 核实；无重编码回写仅针对已验证封装格式，失败保留原文件并报告。
- T5.4、T5.5：工坊模板、数字/标签准确性、混音与响度按阶段验收。
