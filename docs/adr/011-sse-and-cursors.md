# ADR-011：SSE 与事件游标

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

生成、Agent、审批和协作任务持续时间长，浏览器断线不应丢失进度。按照 [实施计划 v2.1 第 2 章](../plan/implementation_plan_v2.md)，采用 SSE + 事件游标，支持断线续接。

执行状态由后端正式记录，客户端根据游标消费进度与状态事件；SSE 连接关闭不等于任务取消。事件消费仍需遵守租户与用户权限。

## 代价与边界

需要处理重连、重复事件、顺序与游标不可续接的情况；事件保留与重新获取快照的行为必须明确，不能让客户端静默停在旧状态。SSE 不是替代数据库版本或持久化步骤日志的另一份正式状态。

## 实施与验证条件

- T0.6、T0.9：任务与 Agent 状态持久化后可被事件接口读取；worker 重启不依赖原浏览器连接存活。
- T0.10、T1.10：未授权及跨租户订阅被拒绝；重连使用游标可恢复，重复事件不会重复应用界面变更。
- T2.12、T4.4：界面断线、重连和游标失效时状态可重新核对；审批/采用仍通过应用服务执行。
