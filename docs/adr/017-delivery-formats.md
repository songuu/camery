# ADR-017：后期交接与格式兼容性

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

公司侧交付前期与已生成镜头，后期由剪映、PR、达芬奇、FCP 或音频工具完成。按照 [实施计划 v2.1 第 2、6 章](../plan/implementation_plan_v2.md)，交付格式选择剪映草稿（取决可行性验证）、FCPXML、EDL（CMX3600）、OTIO、SRT 和 WAV 分轨。

按已采用 ShotTake、素材版本和区间组装，采用实测时长；支持分离对白和反应镜头。输出格式不能表达的样式字幕、多轨或 cue 信息提供明确伴随文件；SRT 不承诺保留颜色，EDL 不承诺完整多轨工程。

## 代价与边界

需要维护目标软件/版本的真实导入回归，不能用 XML/JSON 结构正确代替目标软件接受。剪映支持只有 T0.13 在当前目标版本实测后才能成立；不可行时以 FCPXML / EDL 等交接，不假定私有格式稳定。

AIGC 标识和备案材料按 T0.11 核实的原文、字段、适用格式与规则版本实施；调研提及的法规、经验数值都不因本决策确认而变成已验证事实。

## 实施与验证条件

- T0.13：剪映草稿结论落档为可做或改走 FCPXML 为主；FCPXML / EDL 实际导入 PR、达芬奇，记录目标版本与结果。
- T4.1、T4.2：包含非相邻复用、分离音频、分类字幕和升档素材的黄金集在目标软件中对齐；缺镜、计划/实际差异、cue 和素材授权台账可查。
- T0.11、T4.3：已核实规则的标识写入/回写与校验通过，不支持或失败明确报告并保留原件；元数据检查不能声称全合规。
