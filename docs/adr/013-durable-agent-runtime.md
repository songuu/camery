# ADR-013：自研持久化 Agent 运行时

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

Agent 的多步模型与工具调用需要断点续跑、预算控制和可回放证据。按照 [实施计划 v2.1 第 2、4 章](../plan/implementation_plan_v2.md)，自研运行时，建立在 [ADR-005](005-postgres-durable-execution.md) 的执行引擎上；每次模型调用与工具调用都是持久化步骤。

角色定义声明方法包、工具白名单、模型档位、预算和输出契约。上下文按任务范围构建，来源文字标为不可信数据；运行时处理步数、费用、权限、人工闸门和追踪。

## 代价与边界

需要维护循环、工具结果、异常恢复和日志版本。LLM 输出不保证确定性，可回放是基于已记录输入/结果复现轨迹，不能把重新请求模型当成同一次回放。工具权限与审批不能只靠提示词约束。

## 实施与验证条件

- T0.6、T0.9：模型/工具调用中断后按步骤恢复，结果非法、超时或取消都有明确状态；无重复副作用。
- T0.8、T0.9：制片调度研究 Agent，加载章节切分方法包，回放端到端结果与轨迹可核对。
- 负向测试覆盖越权调用、单写者、来源提示注入、步数/预算熔断、人工闸门及凭据隔离；Agent 不得直接写已采用内容。
- Agent 行为评测报告任务完成率、回路次数、人工升级率与成本，不能用进程启动代替验收。
