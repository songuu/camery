# ADR-019：ShotTake 多对多与版本绑定

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

镜头是成片中的一刀，素材段是模型一次生成的结果；覆盖式拍摄需要同一素材服务不相邻镜头，也需要一个镜头拼接多个素材区间。按照 [实施计划 v2.1 第 2、3 章](../plan/implementation_plan_v2.md)，Shot 与 Segment 通过 ShotTake 多对多关联，绑定具体素材版本及区间，不再用 Shot.segment_id 表示单一归属。

Segment 记录用途、模式、计划时长、头尾余量、优先级和接戏来源版本。ShotTake 记录镜头、Segment 版本、MediaAsset 版本、source_in/out、timeline_offset、声音策略、可见说话状态和采用状态；变速显式记录有理数比例。补段和升档产生新素材与候选，不覆盖旧采用。

## 代价与边界

需要维护源素材区间、目标覆盖、版本与音画同步，素材复用的影响范围必须可见。规划阶段允许无实际媒体的意图，交付前才要求全部采用镜头具备完整有效取用；不能为了通过校验而猜测缺失区间或伪造就绪素材。

声音语义仍来自锁定台词；切反应镜头只改变区间中的可见说话状态，不改已锁文字。出片方式与质量档独立，采用素材升档受预算控制，共享素材不重复计算生成费用。

## 实施与验证条件

- T0.3、T0.4：多对多、非相邻复用、首尾余量、缺镜、版本不符、非法区间、变速、目标覆盖与音轨连续性有确定性/属性测试。
- T0.5、T2.8：采用切换原子更新相关取用并可回退；旧快照迁移不猜测素材采用，修改共享素材标明影响镜头。
- T3.11、T3.12：剪后可用、补段与升档候选采用后覆盖/同步仍通过，原始版本可追溯。
- T4.1、T0.13：包含复用与分离对白的工程实际导入目标软件，按实测时长与具体版本对齐；结构测试不能替代该验证。
