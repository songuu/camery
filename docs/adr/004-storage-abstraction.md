# ADR-004：本地 / NAS / S3 存储抽象

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

私有化客户需要低依赖部署，云端需要对象存储与 worker 扩展。按照 [实施计划 v2.1 第 1、2 章](../plan/implementation_plan_v2.md)，采用存储抽象：私有化默认本地磁盘或 NAS，也支持 S3 兼容存储。

业务对象引用素材身份和版本，由存储边界负责定位实际文件。数据就绪、引用合法、文件存在及哈希匹配是不同检查，不以声明路径代替实物验证。

## 代价与边界

本地文件与对象存储的错误、权限和一致性行为不同，需要契约测试。可移植路径检查不能被描述成操作系统级原子沙箱；素材根目录的访问隔离和并发写入控制仍属于部署与存储边界责任。

## 实施与验证条件

- T0.3：校验相对路径、实际路径边界、文件就绪与 SHA-256；拒绝越界路径、符号链接逃逸、不可识别的文件身份及检测到的读取期改动。
- T0.1、T0.7：服务配置明确素材根目录或对象存储连接；下载产物校验成功后才能入库为就绪素材。
- T4.5：本地 / NAS 的持久挂载与备份恢复通过；S3 实现以同一存储契约验证，不把本地验证外推到全部后端。
