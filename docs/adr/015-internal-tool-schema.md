# ADR-015：内部工具 schema 兼容 MCP

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

Agent 工具需要结构化输入输出、权限与副作用声明，后续也可能对外提供受限能力。按照 [实施计划 v2.1 第 2、4 章](../plan/implementation_plan_v2.md)，内部工具 schema 与 MCP 工具格式兼容。

工具注册表仍由 Camery 管理权限范围、副作用等级和审批令牌；工具调用通过统一应用服务执行。格式兼容不等于已经实现 MCP 传输、会话、发现或对外服务，更不等于开放所有内部工具。

## 代价与边界

需要验证内部定义到协议表示的转换以及错误语义。对外开放时必须另做身份、租户、限流和审计检查，不能把内部可信调用直接暴露。

Studio 1.0 的热点 MCP 工具是 [ADR-018](018-trend-intake.md) 单独明确的外部入口；它有自己的交付任务和权限边界，不等待“未来开放全部平台工具”，也不据此扩展为通用管理接口。

## 实施与验证条件

- T0.9：注册表输入 schema、工具白名单、对象范围、副作用和审批检查可执行，非法调用返回结构化错误。
- T0.8、T0.9：工具契约与输出校验通过；模型输出不能绕过工具权限。
- T1.13、T1.15：热点 MCP 适配与 HTTP / 文件走同一应用服务，额外通过真实协议调用与租户负向测试；内部 schema 验证不能代替此项。
