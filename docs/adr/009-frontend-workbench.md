# ADR-009：工作台 SPA 与编辑视图

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

工作台需要长会话编辑、镜头表、分镜板、时间线和站位机位交互。按照 [实施计划 v2.1 第 2 章](../plan/implementation_plan_v2.md)，采用 React + Vite + TanStack Query + Zustand；时间线基于 Canvas 自研，使用 dnd-kit、wavesurfer.js、Konva（站位/机位图）。

三视图消费同一 IR 与采用状态。服务端状态与编辑交互状态各有职责，界面操作最终通过 ChangeSet，不以本地视图缓存代替正式版本。

## 代价与边界

自研时间线需要维护几何命中、顺序、缩放、音画同步和跨视图一致性；Canvas 不能免除键盘操作与可用性验证。公司侧只有预演、选片和交接所需操作，不扩展为通用后期剪辑软件。

## 实施与验证条件

- T0.1、T0.4：工程和共享时间线代数先行；前端使用模拟 IR 并行时不得声称已完成后端联调。
- T2.7、T2.12、T2.13：站位/机位编辑、三视图编辑、拆并与局部采用 E2E 通过；任意操作后三视图一致，助手修改只产生候选。
- T3.11、T3.12：选片键盘流程与粗剪预览验证，按计划执行选片台可用性基准。
