# ADR-007：Agent → Skill → Tool

日期：2026-11-10。状态：**设计决策已确认，实施按任务验收**。

## 背景与决策

产品需要多角色协作、审查与返工，同时批量产出需要稳定契约。按照 [实施计划 v2.1 第 2、4 章](../plan/implementation_plan_v2.md)，采用 Agent → Skill（方法包）→ Tool 三层；整集剧本、整场拆镜等批量产出使用结构化生成工具。

Agent 负责目标、规划和修正；方法包提供自写方法、规则、样例、方法卡与评测；工具读取 IR、执行检查或提出 ChangeSet。Agent 只能提候选，不能直接修改已采用状态。

## 代价与边界

需要分别维护角色定义、方法包版本、工具契约和评测，不能将一段长提示词当成全部运行时。参考项目的具体文本复用受许可与 provenance 约束，未授权正文不复制。

## 实施与验证条件

- T0.8：方法包注册、路由、输出 schema、来源记录、评测运行器和黄金集可执行；过程、内容、结构、质量断言分别记录。
- T0.9：制片调度研究 Agent，使用章节切分方法包完成回放端到端流程；产出可定位至工具调用及候选。
- 方法包、Agent 定义或模型模式变更运行评测，回退超过配置阈值阻止进入发布；人工抽检与模型评分不能互相冒充。
