# 来源工作台

按[ADR-009](../../docs/adr/009-frontend-workbench.md)使用React、Vite、TanStack Query与内存Zustand。当前提供T1.1来源导入/续读，以及T1.2 StoryBible提取与审阅；项目向导、剧本编辑/采用和完整账号管理仍待实现。

本地开发先启动已配置的API（3000端口），再运行`pnpm dev:web`（仅监听127.0.0.1:5173，`/api`固定代理到本机3000）；生产构建运行`pnpm --filter @camery/web build`，静态目录交给同源API提供。无外部字体、脚本CDN或遥测。

连接时使用受信安装者签发的访问凭证，表单为password且提交后清空。凭证仅保存在JS私有字段，不写入localStorage/sessionStorage、URL或日志；断开会清理身份与所有Query缓存，并请求服务端撤销会话。HTTP请求同源、拒绝重定向、禁用缓存、30秒超时。401清连接，403清当前项目与来源缓存；迟到请求受会话代次、项目和操作身份约束。

上传保留原始字节，UTF-8解码失败明确拒绝，保留BOM/CRLF与emoji。小说客户端固定25万UTF-16单元一批且不拆代理对，文件摘要与批次序号组成幂等身份；重新选择同一文件可恢复已完成批次，遇其它上传插入导致的批次顺序变化时停止。小说文件最多64MB、解码后1600万单元，其它格式最多8MB；服务端仍独立核验所有输入。显示标题最长200字符，原始正文不因显示截断而改写。

来源列表每次加载50条；预览默认12000、最多20000个UTF-16单元与200个相交结构单元。上一段按服务端`before`边界返回紧邻前文，UTF-16代理对不被拆开；写入游标仍严格校验。所有正文均为React文本节点，不执行HTML/Markdown或来源中的指令。小说阅读游标只写当前认证用户；只读角色可保存自己的阅读位置，不能导入。Word暂支持DOCX正文，旧DOC/XLSX不支持。

`pnpm --filter @camery/web test:coverage`检查HTTP客户端、会话与上传编排等纯TS逻辑；TSX视图由SSR边界测试和真实浏览器验收覆盖，不把纯TS覆盖率当作整页交互覆盖率。`pnpm --filter @camery/web typecheck`和`build`验证完整前端。

知识页使用浏览器安全的`@camery/bible/http`白名单契约。按run读取记录、轻量轮询状态，再读取有界候选；点击引文打开该run冻结原文。默认每条实体独立保留，合并建议不自动执行；拒绝实体不会静默移除关联，必须显式取消或恢复。来源过期禁止首次确认但允许拒绝。草稿按run/candidate/review身份隔离，状态刷新不重置同候选编辑；来源页与知识页共享内存会话，403回到来源页显示权限错误。

真实文本模型由[可信宿主](../server/BIBLE-POSTGRES.md)配置。未配置时可查看/审阅已有候选，禁止新提取；UI不接收供应方URL或密钥。知识确认与正式剧本采用分开。浏览器协议夹具用于功能验证，不证明真实推理质量或真人签核。

原创开发页复用当前内存会话与项目权限，使用浏览器安全`@camery/script/http`契约。可先保存一句话创意（默认10集，可调整集数与规划时长），从已保存列表恢复无run的创意，再明确开始新的两阶段开发。设定和分集按字段编辑，人物/规则引用使用选择控件，同名人物保留独立身份；分页查看并可增删结构条目，完整内容超限或引用不完整时阻止确认。原始候选与人工审阅结果分别展示，确认设定后继续分集；重做使用新run。

未确认的保存/开始请求保留同一身份以便网络重试。会话或项目切换销毁对应操作句柄，迟到响应不回填其他工作区；正文与凭证不写浏览器存储。创意变更后旧结果只读、unknown明确等待对账，刷新/查看记录不调用模型。配置与角色安装见[原创开发部署](../../deploy/development.md)，正式开发IR/ChangeSet及真实语义质量继续按阶段1计划实施。

剧作大纲页按需加载，使用独立 `@camery/script/outline/http` 契约。从已审阅原创开发/StoryBible目录选择来源，恢复或保存简报（题材、集数、时长、付费卡点和规则阈值），再明确开始单次预算生成。五件套、题材配方、PlotUnit、季冲突引擎均为普通表单，支持稳定身份、语义引用、增删换序和分页；来源选项展示冻结材料摘要，保留完整真实引用。原候选、人改草稿与历史审阅分开显示，逐辅助题材必须明确选择判断，逐问题豁免必须附理由。已保存的人审依据可随记录恢复。

大纲草稿仅在当前会话/项目内存保留，并按run/candidate/review隔离；刷新、切换标签和切换记录不覆盖草稿，完整页面重载后从已保存目录恢复。保存/开始丢ACK沿用原命令；明确409仍先查询原运行，查询结果不确定时保留原ID。文本配置关闭仍可读写简报、恢复已有人审，正式采用继续由OL-5接入，详见[大纲部署](../../deploy/outline.md)。

大纲实际浏览器验收先执行 `pnpm --filter @camery/web build`，再设置 `CAMERY_BROWSER_DRIVER`（已安装Playwright Node driver绝对路径）、`CAMERY_BROWSER_EXECUTABLE`（已安装Chromium可执行文件绝对路径）并执行 `pnpm --filter @camery/server test:browser:outline`。该独立命令不自动安装浏览器；使用真实Nest/认证/领域HTTP和内存SQL协议、明确合成模型响应，单独记录8组流程及桌面/320px截图，不能代替真实PG、实际文本推理或真人质量签核。普通整仓测试不启动浏览器。
